Privacy & Data

KoffyKraft tools can be used without an account. Work kept only on your device is not uploaded to the KoffyKraft account database.

Cloud saving

When you sign in and choose cloud saving, KoffyKraft stores the account and coffee records needed to provide that service. Cloud records are private by default.

Sharing

A record is shared only when you explicitly use a sharing action. Sharing creates a separate, unguessable link/token. Shared access is view-only unless a future feature clearly asks you to grant another permission. Sharing can be revoked.

Security

Cloud requests are authorized on the server. The server determines record ownership from the signed-in session; a browser cannot choose another user's owner ID. Sign-in codes expire, sessions expire, and authentication tokens are stored by the service only as cryptographic hashes.

Data control

Account holders will be provided controls to export and delete cloud records and to revoke shares. Attachments, when enabled, will use protected file storage rather than public file URLs.

Data minimisation

KoffyKraft collects only information required for the tools, account, saving and sharing functions being used. Anonymous/local use does not require an account.
